# v0.1.64 実装計画書: `publishArticle` / `discardDraftArticle` のエンベロープ `_rev` 抽出修正

- **対象バージョン**: `v0.1.64`（パッチリリース）
- **作成日**: 2026-11-26
- **ステータス**: **実装済み**
- **前提**: `v0.1.63` 実機テストにおいて、`emit publish` / `emit discard-draft` が `HTTP 409 Conflict (Revision precondition did not match)` で失敗する事象が報告され、原因を実コードで確認済み。

---

## 1. 根本原因（実コード検証済み）

1. **エンベロープ剥離による `data._rev` 欠落（[src/sync/orchestrator.ts](file:///Volumes/ext/github/emdash-emit/src/sync/orchestrator.ts)）**:
   - EmDash 実サーバーの単体取得・更新レスポンスは `{ success: true, data: { item: { id, version, ... }, _rev: "<base64>" } }` 形式であり、Track 1 の生トークン `_rev` は `item` 内ではなく外側の `data._rev` に存在する。
   - [src/client/api.ts](file:///Volumes/ext/github/emdash-emit/src/client/api.ts#L61-L114) の `unwrapItem(raw)` は `data.item` のみを返すため、外側の `data._rev` が失われる。一方 `extractRev(raw)` は `root.data._rev`（`envelopeRev`）を読む前提で設計されており、`_rev` が見つからないと整数 `item.version`（例: `"14"`）にフォールバックする。
   - `publishArticle`（初回 GET・`POST .../publish`・公開後再 GET の 3 箇所）および `discardDraftArticle`（初回 GET の 1 箇所）が `unwrapItem()` 済みのオブジェクトを `extractRev()` に渡していたため、`_rev` として整数 `"14"` が送信され 409 Conflict が発生した。
2. **テストモックの形式差異**:
   - [tests/publish_command.test.ts](file:///Volumes/ext/github/emdash-emit/tests/publish_command.test.ts) および [tests/discard_draft.test.ts](file:///Volumes/ext/github/emdash-emit/tests/discard_draft.test.ts) のモックが `{ data: { id, _rev } }`（`item` ラッパーなし）を返していたため、`unwrapItem()` 後も `_rev` が残り不具合を検知できていなかった。

---

## 2. 修正内容

1. **[src/sync/orchestrator.ts](file:///Volumes/ext/github/emdash-emit/src/sync/orchestrator.ts)（全 4 箇所）**:
   - `publishArticle`:
     - 初回 GET: `const getRawJson = await getRes.json(); const rawItem = unwrapItem(getRawJson); const revForTransport = extractRev(getRawJson);`
     - `POST .../publish`: `const publishRawJson = await publishRes.json(); const publishItem = unwrapItem(publishRawJson); finalRev = extractRev(publishRawJson, revForTransport); finalRawItem = publishItem;`
     - 公開後再 GET: `const postPublishRawJson = await postPublishGet.json(); finalRawItem = unwrapItem(postPublishRawJson); finalRev = extractRev(postPublishRawJson, finalRev);`
   - `discardDraftArticle`:
     - 初回 GET: `const getRawJson = await getRes.json(); const rawItem = unwrapItem(getRawJson); const revForTransport = extractRev(getRawJson);`
2. **回帰テスト強化（[tests/publish_command.test.ts](file:///Volumes/ext/github/emdash-emit/tests/publish_command.test.ts), [tests/discard_draft.test.ts](file:///Volumes/ext/github/emdash-emit/tests/discard_draft.test.ts)）**:
   - モックレスポンスを実サーバーと同じ `{ success: true, data: { item: { id, version, ... }, _rev: "<base64-token>" } }` エンベロープ形式へ更新する。
   - `POST .../publish` および `POST .../discard-draft` のリクエストボディに `version` ではなくエンベロープの `_rev` トークンが送信されることを明示的にアサートする。
3. **リリース準備**:
   - `package.json` を `0.1.64` へバンプし、`CHANGELOG.md` に `[0.1.64]` セクションを追加する。
